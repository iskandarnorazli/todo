# Roadmap

The plan of record is the GitHub milestones; this file is their order and why. Every issue has
a milestone. Issues are written to the `issue-writing` skill.

| Milestone | What is true at the end |
|---|---|
| M0 Infra | CI green on Ubuntu and Windows with the scaffold; versions fixed by `expo install`; labels, templates, agent rules |
| M1 Logic | `todosApi`, `validateTitle`, `todosReducer` and `useTodos` done and tested without any UI (T1-T5, T9, T11 logic) |
| M2 UI design | Two or three layouts of the screen compared with the owner on a phone; one chosen |
| M3 UI build | Components and the screen, loading, error, empty states, the form (T6-T11); bonus storage (T12) once D5 is decided |
| M4 Delivery | README with setup, usage and screenshots; every T row names its proof |

M1 issues are independent except `useTodos`, which needs the other three.
